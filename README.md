# 二人麻將 · 試玩 Demo

13 張二人對戰麻將——你 vs AI 莊家。單一花色（萬／條／筒）+ 字牌共 64 張，主打「過水加倍」與完整台型表（1~168 台）。純前端網頁，點開即玩。

**線上試玩**：（部署後填入 GitHub Pages 網址）

## 怎麼玩

1. 選對手（三級難度）→ 選投注額 → 開局。
2. 輪流摸打，可吃／碰／槓，湊成合法牌型即可胡。
3. 喊聽後會圖示提示聽哪些牌、各幾台、剩幾張。
4. 菁英局可「過水」：可胡時選擇不胡，台數 ×2 遞增（上限 ×64）。
5. 胡牌有「對花」小遊戲；聽牌流局有「海底」摸牌。

| 等級 | 技能 | 底注區間 |
|------|------|---------|
| 一般局 | 海底＋對花 | 100 ~ 2000 |
| 高手局 | ＋依投注額看對手部分手牌 | 500 ~ 10000 |
| 菁英局 | ＋看牌＋過水加倍＋限 10 手 | 2000 ~ 100000 |
