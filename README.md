# 二人麻將 · 試玩 Demo

13 張二人對戰麻將——你 vs AI 莊家。單一花色（萬／條／筒）+ 字牌共 64 張，主打「過水加倍」與完整台型表（1~168 台）。純前端網頁，點開即玩。

**線上試玩**：https://benlin-game.github.io/mahjong-2p-demo/

## 怎麼玩

1. 選難度 → 選對手（純外觀）→ 選底注 → 開局。
2. 輪流摸打，可吃／碰／槓，湊成合法牌型即可胡。
3. 喊聽後會圖示提示聽哪些牌、各幾台、剩幾張。
4. 菁英局可「過水」：可胡時選擇不胡，台數 ×2 遞增（上限 ×64）。
5. 胡牌有「對花」小遊戲；聽牌流局有「海底」摸牌。

角色只是外觀，任何難度都能挑。底注為全域階梯 `100～100000`，難度只決定最低底注與技能：

| 難度 | 技能 | 最低底注 |
|------|------|---------|
| 一般局 | 海底＋對花 | 100 |
| 高手局 | ＋依底注看對手部分手牌 | 500 |
| 菁英局 | ＋看牌＋過水加倍＋限 10 手 | 2000 |

> 看牌張數依底注遞增：500→1、1000→3、2000→5、5000→7、10000 以上→9 張。
