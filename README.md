# 二人麻將 · 試玩 Demo

13 張二人對戰麻將——你 vs AI 莊家。單一花色（萬／條／筒）+ 字牌共 64 張，主打「過水加倍」與完整台型表（1~168 台）。純前端網頁，點開即玩。

**線上試玩**：https://benlin-game.github.io/mahjong-2p-demo/

## 怎麼玩

1. **入桌**：調投注額 → 開局（對手每局隨機、播 VS 過場）。**注額決定桌型**，不用另選。
2. **定莊＋發牌**：擲兩顆骰子定莊（點數和單→你、雙→對手）→ 入桌拿牌動畫 → 開打。
3. **對局**：輪流摸打，可吃／碰／槓，湊成合法牌型即可胡。
4. **喊聽**：喊聽後會圖示提示聽哪些牌、各幾台、剩幾張。
5. **過水**（三桌通用）：可胡時選擇不胡，台數 ×2 遞增（上限 ×64）。

**桌型由投注額決定**：一支 stepper 橫跨當前資產區間的 8 個底注檔，檔位落點決定桌型（檔 1–2 新手／3–5 高手／6–8 大師），上方色塊隨之變色（綠／藍／金）。三桌規則完全一致，往上走只加碼風險與獎勵：

| 桌次 | 本場寶牌 | 對手強度 | 出牌秒數 |
|------|------|------|------|
| 新手桌（綠） | 1 張 | 普通（不防守） | 8 秒 |
| 高手桌（藍） | 2 張 | 中（會防你的聽牌） | 5 秒 |
| 大師桌（金） | 3 張 | 強（防守嚴謹） | 3 秒 |

> 持有資產需 ≧ 投注額×16；不足仍可選、開局跳請儲值提示。（出牌秒數目前為顯示文案。）
